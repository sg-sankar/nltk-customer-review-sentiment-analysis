# Python NLTK: Customer Satisfaction Analysis

This repository contains a project notebook for analyzing customer reviews using Natural Language Processing (NLP) with Python and the NLTK library. The project was completed as part of a certification focused on real-world text data analysis.

## 🔍 Project Overview

This project walks through the key steps in understanding and analyzing customer satisfaction through textual reviews. Tasks include:

- Loading and exploring the customer reviews dataset
- Cleaning and preprocessing text data
- Tokenization and stopword removal
- Extracting adjectives for product insight
- Performing sentiment analysis
- Practice and challenge tasks for hands-on learning

## 🛠️ Tech Stack

- Python
- NLTK
- Pandas
- Jupyter Notebook

## 📁 Files

- `The Notebook(1).ipynb` – Complete walkthrough of the project steps

- Insights into customer sentiment and feedback patterns
